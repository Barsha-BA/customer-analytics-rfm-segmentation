
# Customer Analytics & RFM Segmentation

## Problem
Analyse customer behaviour and segment customers based on value to improve retention and marketing effectiveness.

## Tools Used
- SQL (BigQuery)
- Data Cleaning
- RFM Segmentation

## Approach
- Cleaned customer and transaction data
- Performed analysis using SQL (joins, aggregations)
- Created RFM segments (Recency, Frequency, Monetary)
- Analysed customer behaviour across loyalty tiers and engagement

## Key Insights
- High-value customers show higher engagement and spending
- Engagement strongly correlates with revenue
- Loyalty level impacts behaviour and discount usage

## Business Impact
- Enables targeted marketing campaigns
- Improves customer retention strategies
- Helps increase customer lifetime value
